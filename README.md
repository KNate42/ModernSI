# ModernSI

Independent international student platform: one hub for student ideas, events and community.
ModernSI is an independent student project and is not affiliated with, endorsed by, or sponsored by any university.

## Layout

- `design/mock/` static homepage and intro mock for design sign-off
- `backend/` FastAPI modular monolith
- `frontend/` Next.js application
- `infra/` docker compose files for the stores
- `docs/` specifications and plans
