## Pixel check of the needs-review text (one-off probe, not kept in the repository)
For each needs-review color-contrast node of 20 routes (home, home signed in, ideas, 4 idea pages, events, an event, join, about, academic, community, personal, idea form, settings, 404, error page, forgot, idea live, review) in both themes on both screens, the probe hid the text, took a screenshot of the box behind it and measured the contrast of the real text colour against every pixel.
900 elements measured. Median pixel contrast reached the AA limit (4.5, or 3 for large text) for 899 of 900; the one exception is the h1 'Hi, Routes Author' on a phone in the dark theme, whose words sit inside a butter marker (the probe sets the h1 colour against the marker, the real pair --on-butter on --butter is 13.01:1 in the palette check above).
658 of the 900 are plain text elements (no marker, box or title colour nested inside): all 658 have median >= the limit. The thinnest margin is 4.59:1 against 4.5 (the breadcrumb link, --accent-text on --tint-steel, light theme); where a letter of the same link lies on the centre of one of the 1.3 px dots of the band the contrast falls to 3.34:1 (4.46:1 at the first percentile of its pixels), so under 1% of the link.
84 elements have a 5th-percentile pixel below the limit: all 84 are marker boxes or titles that contain one (the clip of a marker box includes its own navy border, which has the text colour), none is plain text.

## Defects found and fixed in this pass
1. Pages that call notFound() or fail (for example a missing idea, the review queue for a guest, the error page) are rendered again in the browser by Next, and React then wiped data-theme and data-motion from <html>: the 404 showed the light theme to someone who had chosen dark, and on a phone the header had no burger and its links spilled over the bar. Found by routes.spec (theme check); fixed with one shared function (lib/boot.ts) that the head script and the new PageState component both run, before the first paint.
2. A profile without bio, languages, interests or links showed an empty page under the title. It now says so, with a way to fill it in for the owner.
3. One icon set: the homepage icon wrapper, the phone bar, the header, the theme switch and the user menu drew their own svg icons; they use components/Icon.tsx now. The hand note is one shared component (components/HandNote.tsx) instead of three copies.
4. Dead code removed: the .old-home block in globals.css (41 lines), the home icon wrapper, the duplicated hand-note markup.
5. The wall button for an empty network said 'Propose the first idea'; the site says Pitch everywhere else, so it is 'Pitch the first idea'.
6. shell.spec: the phone bar check measured the footer before the new page had finished growing; it now waits for the page and measures until the result is stable.
